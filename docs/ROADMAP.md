# Decision Matrix AI Roadmap

## Цель продукта

Decision Matrix AI — веб-приложение, помогающее принимать сложные решения с использованием структурированной матрицы и искусственного интеллекта.

Главная ценность продукта — не только расчет итогового результата, но и объяснение каждой рекомендации ИИ.

---

# Направление 1. Product

## Этап 1. Public MVP

- подготовка production
- публикация в Интернет
- автоматический деплой

## Этап 2. User Accounts

- регистрация
- авторизация
- личный кабинет
- приватные проекты

## Этап 3. AI Assistant

- описание проекта
- рекомендации альтернатив
- рекомендации критериев
- рекомендации весов
- рекомендации оценок
- объяснение рекомендаций
- AI-отчет

# Направление 3. Growth

Развитие продукта ведется в отдельном чате.

Основные направления:

- Customer Development
- интервью пользователей
- продвижение
- позиционирование
- монетизация
- поиск первых клиентов

---

# Принципы

- маленькие спринты
- рабочее приложение после каждого завершенного этапа
- production-публикация при минимальной стоимости
- архитектура должна позволять заменять отдельные компоненты без переписывания системы
