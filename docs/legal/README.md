# Юридические документы

Утверждённые встроенные тексты находятся в `app/legal_content/`:

- `terms.md` — Пользовательское соглашение;
- `privacy.md` — Политика в отношении обработки персональных данных;
- `consent.md` — Согласие на обработку персональных данных.

Если в базе уже есть опубликованные версии, публичные страницы показывают их. После выпуска новой версии администратор открывает `/admin/legal-documents`, проверяет предзаполненный текст, сохраняет черновик и отдельно подтверждает публикацию. Публикация запускает обязательное подтверждение новой редакции зарегистрированными пользователями.

Правила cookie и интерфейс изменения выбора находятся на `/cookies`; согласие на необязательную аналитику не объединяется с согласием на обработку персональных данных при регистрации.
