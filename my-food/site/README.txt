«Моя еда» v0.10.1 / Worker v2.3 — ИИ выбирает блюда, массу, КБЖУ на 100 г, при необходимости самостоятельно обращается к справочникам.

Новая редакция согласованного пользователем системного промпта в `my-food/worker/prompt.js`. Распознавание текста и фотографий еды/текста через Gemma 4 на Cloudflare AI. Она может вызвать `search_nutrition` (подключённые пищевые справочники), `search_official_menu` (данные «Вкусно — и точка») и `web_search` (опциональный Cloudflare Web Search API при наличии AI Gateway credits). Ошибки внешнего поиска не блокируют распознавание: модель даёт приблизительные КБЖУ на 100 г по своим знаниям.

Worker НЕ проверяет КБЖУ по другим справочникам, НЕ сравнивает цифры и НЕ возвращает HTTP 422 при неполном наборе блюд. Поскольку приоритет — полезный результат, модель может вернуть status:partial. Клиент сразу показывает все полученные карточки, рассчитывая КБЖУ порции из per100 и веса ИИ, оставляя неизвестные поля пустыми. Каждая карточка сохраняется независимо; неполные можно дополнить вручную.

Существующие история и избранное хранятся в IndexedDB и сохраняются при развёртывании. Публикация Worker и PWA автоматически запускается через GitHub Actions по изменению файлов в ветке `codex/my-food-cloudflare-cicd` (не в основной ветке `decision-matrix-ai`).

Официальный каталог сети «Вкусно — и точка» представляет снимок PDF с отдельными обновлёнными строками; до обновления снимка нельзя обещать полностью актуальные значения. Если Web Search API недоступен, модель использует разумные приблизительные показатели.

--- Предыдущая история изменений ---

«Моя еда» v0.10.1 / Worker v2.0 — переход на AI-first КБЖУ.

Поток: пользователь отправляет текст или фото; Gemma 4 определяет целое блюдо и его массу и КБЖУ на 100 г ИЛИ раскладывает на ингредиенты, возвращая массу и КБЖУ на 100 г каждого. Приложение рассчитывает итоговые значения только из этих данных. Внешние справочники не заменяют оценку ИИ: после получения ответа выполняется независимое сравнение КБЖУ на 100 г; отклонение более чем в 1,5 раза отражается в Технической диагностике. Для фотографии с текстом модель читает текст и использует ту же логику.

Все пользовательские записи и избранное остаются в IndexedDB в браузере iPhone. Исходный текст и фотография сохраняются до окончания работы с распознанными карточками либо очистки.

«Моя еда» v0.9.16 / Worker v1.20: составное блюдо может содержать начинку в additions. Проверка учитывает items + additions, а масса основного ингредиента для составных блюд берётся из строки ingredients, если расходится с полем заголовка. Справочники по компонентам ищутся сразу, одним пакетом.

«Моя еда» v0.9.15 / Worker v1.19
Исправлена проверка составных порций с начинкой (2 блина, каждый с творожным сыром и слабосоленой семгой). Проверяются компоненты одного блюда, без разделения на независимые блюда; масса определяется только ИИ. Сетевые ошибки Safari сообщаются понятным текстом; исходный текст сохраняется.

Моя еда v0.9.14 / Cloudflare Worker v1.18

Деплой: GitHub Actions из ветки codex/my-food-cloudflare-cicd.
Бэкенд Worker: food-ai-inference; PWA Worker: drop-443886b1-4e5 (Workers Static Assets).

Изменения:
- Новый контроль полноты перечня по явно выделенным частям исходной фразы, без программного определения веса.
- Если нейросеть пропустила одну из частей, Worker отдельно запрашивает пропущенный продукт у ИИ, и затем пересчитывает общий список.
- Если восполнить продукт не удалось, Worker возвращает ошибку и приложение сохраняет исходный текст вместо неполного списка.
- Техническая диагностика показывает фрагменты исходной фразы и восстановленные позиции.
- Обновлена версия PWA и кэш приложения.

Контрольный тест: «2 яйца, 20 г печени трески и соус тартар 10г» — три отдельные позиции, вес печени 20 г, соуса 10 г, вес двух яиц оценивает нейросеть. Для каждого блюда рассчитываются КБЖУ по найденным справочным данным.

Резерв КБЖУ: опубликованная этикетка консервированной печени трески JUOR (525 ккал, Б6, Ж55.46, У<0.5 на 100 г), только как приблизительный аналог; сырой продукт — Matvaretabellen. Никогда не использовать масло печени трески вместо самой печени.
