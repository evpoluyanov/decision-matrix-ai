Моя еда v0.9.14 / Cloudflare Worker v1.18

Деплой: GitHub Actions из ветки codex/my-food-cloudflare-cicd.
Бэкенд Worker: food-ai-inference; PWA Worker: drop-443886b1-4e5 (Workers Static Assets).

Изменения:
- Новый контроль полноты перечня по явно выделенным частям исходной фразы, без программного определения веса.
- Если нейросеть пропустила одну из частей, Worker отдельно запрашивает пропущенный продукт у ИИ, и затем пересчитывает общий список.
- Если восполнить продукт не удалось, Worker возвращает ошибку и приложение сохраняет исходный текст вместо неполного списка.
- Техническая диагностика показывает фрагменты исходной фразы и восстановленные позиции.
- Обновлена версия PWA и кэш приложения.

Контрольный тест: «2 яйца, 20 г печени трески и соус тартар 10г» — три отдельные позиции, вес печени 20 г, соуса 10 г, вес двух яиц оценивает нейросеть. Для каждого блюда рассчитываются КБЖУ по найденным справочным данным.

Резерв КБЖУ: опубликованная этикетка консервированной печени трески JUOR (525 ккал, Б6, Ж55.46, У<0.5 на 100 г), только как приблизительный аналог; сырой продукт — Matvaretabellen. Никогда не использовать масло печени трески вместо самой печени.
