Сервис может обрабатывать:

Пользователю не следует передавать через Сервис паспортные, медицинские, платежные и иные чувствительные персональные данные без необходимости.

Данные обрабатываются для:

Оператор может осуществлять сбор, запись, систематизацию, хранение, уточнение, использование, обезличивание, блокирование и уничтожение персональных данных с использованием средств автоматизации.

Данные хранятся не дольше, чем это необходимо для целей их обработки либо предусмотрено законодательством.

При сборе персональных данных граждан Российской Федерации Оператор соблюдает требования законодательства Российской Федерации о локализации персональных данных.

Оператор не продает персональные данные.

  • моделей искусственного интеллекта;
  • иных технических сервисов, необходимых для работы Decision Matrix AI.

Передача осуществляется в объеме, необходимом для работы соответствующей функции.
